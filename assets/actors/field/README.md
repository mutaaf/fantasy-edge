# Field actor assets

Everything here is generated by the scripts in `tools/blender/field/`. Nothing is hand-painted. Regenerate in this order:

```bash
blender -b --factory-startup --python tools/blender/field/bake_turf.py -- natural     # ~7 min, Metal GPU
blender -b --factory-startup --python tools/blender/field/bake_turf.py -- synthetic
blender -b --factory-startup --python tools/blender/field/make_markings.py            # ~15 s
blender -b --factory-startup --python tools/blender/field/make_field_maps.py          # needs the turf ORM
python3 tools/blender/field/manifest.py
```

`manifest.json` lists every file with its role and GPU cost. It also lists the places where the scene's rules table disagrees with the rulebooks.

## Turf (`turf/<variant>/`)
Each tile is a 0.40 m square of real blade geometry, baked top-down by Cycles:
- **Natural:** about 260,000 blades per m², around 22 mm tall.
- **Worn:** thinner, flattened and browned.
- **Synthetic:** 3/8 in gauge tufts over crumb-rubber infill.

Maps:
- `*_albedo` (sRGB).
- `*_normal`: OpenGL convention, +Y up.
- `*_orm`: R ambient occlusion, G roughness, B height over 45 mm.

Mowing stripes are physical, not painted:
- Natural turf is baked twice from the same blade layout, leaning with the mower (`with_normal`) and against it (`against_normal`).
- A renderer blends the two normals by a mowing-pattern mask, so the stripe changes as the viewer moves, the way real turf does. Albedo and ORM are shared.
- A cheap renderer can add `visual.field.stripeTint` instead.

`shell_0..7`, at 512 px, are coverage slices from tall to short. They're for shell or fin grass within a few metres of the eye. Beyond that, fade to the flat material.

`paint_breakup` tiles with the turf and says how much paint a texel carries: blade tips more, soil less.

## Markings (`markings/<league>/`)
- `paint_sdf.png`: a signed distance field at 16 texels per yard over a canvas of x −16..116, y −14..67.33 yards. R is white paint, G is yellow. 0.5 is the edge, and the range is ±12 in.
  - **Threshold at 0.5** for a hard, correctly sized line at any distance.
  - **Subtract `(paint_breakup − 0.5) × k`** before thresholding, so the edge sits in the grass.
  - **Use `smoothstep` just outside 0.5** for overspray.
- `markings.json`: the same markings as polygons and triangles in field yards, each with the rule it came from. A renderer can draw decal geometry from it instead.
- Sources:
  - NFL 2026 Official Playing Rules, Rule 1 and the field diagram notes.
  - NCAA 2026 Football Rules, Rule 1-2.

Numerals use Graduate (SIL OFL 1.1, `fonts/`), with the zero's centre dot removed because field numerals have none.

## Field maps (`maps/<league>/`)
Same canvas as the markings.
- `field_maps`: R macro variation, G wear, B mowing crispness, A divot density.
- `mow_patterns`:
  - R: five-yard bands.
  - G: ten-yard bands.
  - B: checkerboard with rows the hash spacing wide.
  - A: diagonal diamonds.

`maps/divots*`: a 2×2 decal atlas of divot scars with torn sod, plus its normals.

## Team art
`tools/blender/field/teamart.py` (stdlib) lays out end-zone names and a generic midfield ring from the scene's team names as triangles in field yards:
- It uses the rulebook clearances: 4 ft from any line in the end zones, and off the hashes and numbers at midfield for college.
- Tints: `team.primary`, `team.secondary`.
- It draws no club marks.
