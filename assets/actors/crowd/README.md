# Crowd kit

24 fans, generated by `tools/blender/crowd/build.py` (Blender 5.2, headless,
deterministic). Nothing here is hand-edited and nothing is downloaded: every
body, garment, prop, pose and texture is built by the scripts beside it.

```
blender --background --python tools/blender/crowd/build.py
blender --background --python tools/blender/crowd/lineup.py       # review: the cast in rest pose
blender --background --python tools/blender/crowd/pose_review.py  # review: poses on four builds
```

`manifest.json` is the contract: skeleton, fans, clips, atlas layouts, tint
channels, LOD triangle counts. A renderer should read it, not this page.

## The cast

| Axis | Spread (24 fans) |
|---|---|
| Build | petite 5, average 5, heavy 4, broad 4, teen 4, slim 2; heights 1.45–1.92 m |
| Skin | 8 tones, light to deep, each worn by at least two fans |
| Top | jersey 6, hoodie 5, jacket 5, tee 4, pullover 4; about a quarter wear no club colour |
| Head | beanie 6, visor 5, cap backwards 5, cap 3, none 5; hair short, buzz, long, ponytail, curly, bald |
| Held | towel 5, foam finger 5, phone 5, blank sign 5, nothing 4 |
| Also | club scarves, face paint (stripes, cheek, half), sleeve stripes |

Club colour is never baked in. Clothing that takes a club colour carries a
0.86 luminance in the albedo, and the mask says which chip multiplies in:
**R** primary chip, **G** secondary, **B** face paint (primary).

## Files

| File | What | Budget |
|---|---|---|
| `fanNN.usdz` / `.glb` | skinned LOD0 (~1500 tris) + LOD1 (~420 tris), 20-joint skeleton, 10 clips | per fan |
| `lod0_poses.usdz` / `.glb` | every fan's LOD0 frozen in each of the 6 impostor poses, static | 216k tris on disk, not drawn at once |
| `lod1_poses.usdz` / `.glb` | the same at LOD1 | 60k tris on disk |
| `fan_albedo.png` | mesh UV atlas, 2048², 6 x 4 fan cells, faces at 1.75x texel density | 16 MB RGBA in GPU |
| `fan_mask.png` | tint mask, 1024² | composed on load, not kept |
| `impostor_albedo.png` | 2560x2304: 8 fan blocks per row, 5 views x 6 poses, 64x128 px cells | 23.6 MB RGBA |
| `impostor_mask.png` | 1280x1152 | composed on load, not kept |
| `impostor_normal.png` | 1280x1152, view space, +Z toward the viewer | 5.9 MB |
| `variation.png` | 256² per-seat phase, fan index (no shared 3-neighbours), tint jitter, pose bias | 0.3 MB |

Clips (24 fps): `idle_sway` (56f, loop), `sit` (hold), `stand` (16f), `clap` (12f, loop),
`cheer` (16f, loop), `fist_pump` (12f, loop), `towel_spin` (12f, loop), `wave` (32f),
`groan` (40f), `phone_raise` (44f). glTF carries one animation per clip; USD has one
timeline with the clips end to end, ranges in the manifest's `usdClips`.

Impostor poses: `sit`, `sit_b`, `stand`, `clap_b`, `cheer_a`, `groan`. Views at yaw
0, 45, 90, 135, 180 (fan relative to the viewer, +90 facing the viewer's right);
225–315 are the mirrors of 135–45. Camera elevation 12°. A cell covers 1.2 x 2.4 m
with the pivot at bottom centre.

## Draw strategy

Fans move by group, never per fan on the CPU (docs/ART_BIBLE.md):

- **Near** (a few rows around the wearer): LOD0 pose meshes merged per group. A
  group swaps which merged pose mesh it shows.
- **Mid** (to ~12 yd): LOD1 pose meshes, the same way.
- **Far**: one quad per fan, cut from the view the fan is seen at, merged per
  slice of the bowl. A group changes pose by moving its material's texture
  transform down one atlas row.

At the actor's default rings (24 LOD0, 140 LOD1, the rest cards) the crowd draws
about 36k + 59k tris of mesh plus 2 tris a card, in 4 + 4 + 24 draw parts.

Axes: both exports are +Y up with fans facing +Z, metres, origin on the floor
under the pelvis. Seated, the pelvis sits 0.30 m behind and 0.52 m above the
origin (for a 1.75 m fan).
